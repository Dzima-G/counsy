# Советник

![CI](https://github.com/Dzima-G/counsy/actions/workflows/ci.yaml/badge.svg)

## 📌 Основная информация

AI-помощник, который понимает документы компании (договоры, регламенты, инструкции) и с указанием точного источника
отвечает сотруднику на вопросы по ним.

### Решаемые задачи

#### Проверка договоров

Сверяет договор с внутренними нормами компании и даёт отчёт:

- что не соответствует принятым в компании требованиям
- ключевые условия — форс-мажор, гарантии, сроки, штрафы, порядок расторжения и др.

#### Поиск по документам компании

Отвечает на вопрос сотрудника, указывая точный документ и ссылку, откуда взят ответ.

#### Контроль актуальности документов

Регламенты и инструкции часто ссылаются друг на друга. Когда один из них обновляется, приложение проверяет документы,
которые на него ссылаются, и показывает:

- где новая версия противоречит уже существующим документам
- что конкретно нужно проверить и поправить, чтобы вся цепочка документов оставалась согласованной
- *в перспективе — то же самое для внешних нормативов (изменения законодательства, отраслевые нормы), на которые
  опирается компания.*

### Принцип работы

Приложение не «придумывает» ответ, если не уверено. Если документ устарел или противоречит другому — это явно
помечается, а не смешивается в один ответ. Если точного ответа в документах компании нет — об этом говорится прямо,
вместо правдоподобного, но неверного ответа.

## 🚀 Технологии

- **FastAPI** — фреймворк для построения быстрых REST API.
- **PostgreSQL** — реляционная база данных
- **SQLAlchemy** — работа с данными и моделями
- **Docker** — контейнеризация приложения

## 🔐 Переменные окружения

Образ считывает настройки из переменных окружения.
Создайте файл `app/core/.env` (пример `.env.example`) и запишите туда данные в формате: `ПЕРЕМЕННАЯ=значение`.

- **`DEBUG`** — настройка для включения отладочного режима.
  Принимает значения `TRUE` или `FALSE`.
- **`DB__URL`** — адрес для подключения к базе данных PostgreSQL.
  Другие СУБД не поддерживаются.
  [Документация SQLAlchemy](https://docs.sqlalchemy.org/en/21/core/engines.html)
- **`ENVIRONMENT`** - настройка окружения.
  Принимает значения `develop` или `production`.

## Как запустить

### 🐳 Запуск локально в Docker

Код в репозитории полностью докеризирован, поэтому для запуска приложения вам понадобится Docker.

1. Подготовить окружение к локальной разработке:
   Для запуска необходим установленный [Docker Desktop](https://www.docker.com/get-started/).
2. Собрать и поднять контейнеры с помощью docker-compose:

```shell
docker compose up --build
```

3. Примените миграции:

```shell
docker compose exec web uv run alembic upgrade head
```

4. Откройте в браузере:

   Swagger UI доступен по адресу: http://127.0.0.1:8010/docs
